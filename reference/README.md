# reference/

Drop ISET screenshots, exports and specs here.

Everything in this folder except this README is gitignored. It is meant for
material taken from the live ISET portal — real counterparty names, tariffs,
bank details and volumes — which must not reach the GitHub remote.

Suggested layout, though nothing enforces it:

    reference/
      screens/        screenshots of ISET pages
      exports/        CSV / Excel pulled from ISET
      specs/          SRS, feature notes, circulars

If a file here turns out to be safe to keep in the repo (a blank template, a
published circular), move it out of this folder deliberately rather than
un-ignoring it.
